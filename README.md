# Terraform AWS VPC Project 🚀

This project demonstrates how to create an AWS VPC and Public Subnet using Terraform.

## Project Overview

In this project, I created a custom AWS VPC and a Public Subnet using Terraform. This project helped me understand basic AWS networking and Infrastructure as Code.

## Technologies Used

- Terraform
- AWS VPC
- AWS Subnet
- AWS CLI
- Git
- GitHub

## Features

- AWS Provider configuration
- Custom VPC creation
- Public Subnet creation
- Variables for reusable values
- Outputs for VPC ID and Subnet ID
- GitHub version control

## Terraform Commands Used

```bash
terraform init
terraform validate
terraform plan
terraform apply
terraform output
terraform destroy
Output
